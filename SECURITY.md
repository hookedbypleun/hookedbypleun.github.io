# Beveiliging — Hooked by Pleun

Hooked by Pleun is een kleine hobby-shop van een minderjarige haakster, onder begeleiding en verantwoordelijkheid van haar ouders.

## Iets gezien dat niet klopt?

Meld het niet publiek (geen GitHub-issue), maar stuur een berichtje via het [bestelkanaal](https://hookedbypleun.github.io/bestellen.html) met "voor de ouders". We kijken er zo snel mogelijk naar.

## Uitgangspunten

- Geen accounts, geen betaalgegevens op de site; bestellen loopt via WhatsApp.
- Geen cookies; alleen een anonieme bezoekersstatistiek.
- Beheer gaat via een afgeschermde Cloudflare Worker; secrets staan nooit in deze repo.

Openstaande verbeterpunten worden privé bijgehouden.
